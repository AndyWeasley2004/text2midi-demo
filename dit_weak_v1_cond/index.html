Latent DiT — weak stage, conditional samples

The 397.2M-parameter latent DiT trained for 120K steps on the weak corpus in the window-VAE latent space (one 128-d latent per second, rectified flow, 192 s canvas), sampled from dit_weak_v1/final EMA weights with classifier-free guidance 3.0 and 50 Euler steps, seeds 101–103, and decoded through the grammar-constrained decoder inference/latent_decode.py.

The prompts are identical to the AR middle/Lyria demos — the same five attribute/key/tempo prompts and the same plainer sentiment sentences. Unlike the AR model, the DiT takes the section plan and the piece length as a time-aligned input rather than generating them, so each prompt borrows its plan and length from a Lyria validation piece with the same emotion and genre: happy pop ← sample_001071 (105 s, A B C B); sad classical ← sample_000018 (160 s, A B C D E); calm jazz ← sample_001082 (150 s, A B C D C E); angry classical ← sample_005379 (150 s, A B C B D); anxious pop ← sample_005294 (130 s, A B C D). The plan is drawn only inside the roll, as translucent colored spans carrying the section letter.
